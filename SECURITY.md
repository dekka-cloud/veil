# Security

If you find a way to make Veil miss personal information it should find, leak a value it was meant to protect, or crash on input it should handle, please report it privately through [GitHub's private vulnerability reporting](https://github.com/dekka-cloud/veil/security/advisories/new) rather than in a public issue. We'll confirm we've received it, work on a fix with you, and credit you when it ships unless you'd rather we didn't.

A finding Veil misses in ordinary text isn't a vulnerability; open an issue with an example, using made-up values, so we can add it to the tests.
